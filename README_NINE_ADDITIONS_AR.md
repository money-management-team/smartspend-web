# SmartSpend — نسخة الفرونت مع الإضافات التسع

المشروع الكامل مبني على آخر ملف `Front.zip` المرفق، مع المحافظة على العمليات المالية والصوت والفواتير وسجل الحساب وقوالب PDF السابقة.

الإضافات: سجل التصنيف، مركز الانتباه، المراجعة الشهرية، كشف الحساب PDF وCSV، قوالب الإدخال، العروض المحفوظة، تخصيص لوحة التحكم، دليل البداية، وإخفاء المبالغ.

ابدأ من [دليل الإضافات والتشغيل والتحقق](docs/frontend-experience/FRONTEND_NINE_ADDITIONS_AR.md). يتضمن مكان كل إضافة، تفاصيل المنطق، الملفات المهمة، وطريقة تجربة الميزات قبل النشر. وقائمة الملفات الجديدة والمعدلة في [CHANGED_FILES.md](docs/frontend-experience/CHANGED_FILES.md).

احتفظ بإعدادات `.env` الحالية، ثم نفّذ داخل المشروع:

```powershell
npm ci
npm run dev
```

نتيجة التحقق: **197 اختباراً ناجحاً**، و`npm run lint` و`npm run build` ناجحان. أُجري فحص PDF متعدد الصفحات بالعربية والإنجليزية. لا يتطلب هذا الإصدار تعديل الباك إند أو إعدادات Laravel Cloud.
