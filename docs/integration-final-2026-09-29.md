هذا التوثيق يشرح ربط الواجهة المبني على آخر نسخة `SmartSpendWeb`. تضمنت حزمة التسليم الحالية تعديلًا صغيرًا للباك إند لعرض الحسابات المؤرشفة، موضحًا في قسم تحديث الحسابات أدناه. بقيت بقية تدفقات Laravel كما هي.

| المجال | ربط الواجهة | التحقق وحالة الطلب |

## نقاط التكامل والنشر

1. ثبّت الاعتمادات ثم شغّل `npm run lint` و`npm run build` في مجلد `SmartSpendWeb`.
2. انشر تحديث الباك إند لعرض الحسابات المؤرشفة، ثم ضع عنوان API المناسب في إعدادات البيئة وفق `.env.example` وانشر الفرونت إند الجديد على Vercel. لا تُضمّن قيم `.env` المحلية في ملف التسليم.
3. اختبر بحساب شخصي له أهداف ادخار وحساب مصدر بنفس عملة الهدف: اقتراح من المحادثة، واقتراح من الرؤى، ومراجعة المبلغ والحساب قبل تأكيد المساهمة.
4. اختبر إنشاء PDF المحلي وتنزيله، واختبر CSV/XLSX ومتابعة سجلهما بعد اكتمال المهام الخلفية.
5. اختبر تصفية واردات لها حالات وصفوف متعددة، ثم عدّل صفًا وتأكد من إعادة تحميل الصفحة المصفاة.

لا تتضمن عقود الباك إند الشخصي الحالية واجهات لتسجيل الشركات أو إدخال صوتي للمساعد. هاتان ميزتان منفصلتان تتطلبان عقودًا خلفية قبل ربطهما ربطًا حقيقيًا.
